# Security Policy

## Supported Versions

| Version | Supported          |
| :--- | :--- |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The LocalBite engineering team takes the security of vendor and customer financial and identity data seriously.

If you discover a security vulnerability:
1. **Do not create a public GitHub issue.**
2. Send an email to `security@localbite.com` with:
   - Description of the vulnerability.
   - Steps to reproduce or proof of concept.
   - Potential impact.
3. We will acknowledge receipt within 48 hours and work with you on a responsible disclosure timeline.
